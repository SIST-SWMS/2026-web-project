# 👟 신발 쇼핑몰 및 물류/재고 관리 시스템 

> Java, Oracle 기반의 사용자 맞춤형 신발 쇼핑몰 및 웹 관리자 시스템
> **벤치마킹 사이트:** 풋마트, 무신사 킥스, ABC마트, 다나와

## 👥 팀원 및 역할 분담

| 이름 | 역할 | 담당 세부 업무 |
|------|------|----------------|
| 주은주(팀장) | 관리자 / 재고 | 공통 파일 관리, 관리자 대시보드, 재고 입출고 관리 시스템 |
| 유호빈(부팀장) | 상품 / 전시 | 상품 목록, 상품 상세 페이지 구현, 상품 검색 |
| 이지현 | 장바구니 / 결제 | 장바구니 리스트 구현, 주문 및 구매 프로세스 |
| 이윤호 | 리뷰 / 문의하기 | 상품 리뷰 및 문의 게시판, 관리자 답글 처리 |
| 송혜림 | 마이페이지, 회원가입 | 마이페이지 관리, 회원가입, 로그인 |

##  주요 구현 기능 (수정 및 추가 예정-임시)

| 카테고리 | 기능명 | 상세 설명 |
|----------|--------|-----------|
| **관리자 / 재고** | 통합 대시보드 | 관리자 전용 대시보드를 통한 주문, 매출, 통계 차트 확인 |
| | 물류 흐름 제어 | 실시간 재고 조회, 수동 입고 처리 및 반품 시 DB 롤백 로직 적용 |

| | 주문 상태 관리 | 결제완료 → 배송중 → 배송완료 → 구매확정/취소/반품 상태 제어 |

| | 1:1 문의 게시판 | 작성자와 관리자만 열람 가능한 비밀글 로직 및 관리자 답글 처리 기능 |

##  트러블슈팅 (Troubleshooting)

## 🚨 트러블슈팅 (Troubleshooting)

| 작성자 | 아쉬운 점 | 개선한 점 | 향후 개선방향 |
|---|---|---|---|
| **이지현** | • 주문 완료 시 주문번호 생성, 주문 목록 추가, 주문 상세 내역 추가를 트랜잭션을 통해 동시성 문제를 해결해야했으나 서로 다른 sqlSession을 사용하여 로직을 처리함<br>• DB에서 사이즈 목록을 가져와서 출력해야하는데 하드코딩 되어있음 | • 개발 도중 장바구니-재고-상품 테이블의 조인문이 잘못 연결되어 장바구니에서 상품 번호로 출력해야할 목록이 재고 번호로 출력되고 있음을 알았고, 조인문을 수정하여 장바구니 상품이 정상적으로 출력될 수 있도록 수정함 | • 트랜잭션을 사용하여 오류 발생시 DB에 값이 변경되지 않고 rollback 될 수 있도록 개선<br>• DB에서 값을 가져와 출력하는 방식으로 하드코딩 하지 않도록 개선<br>• 유사한 기능의 메소드를 나누는 대신 하나로 처리할 수 있도록 개선 |
| **주은주** | • 재고 차감 시 재고 번호를 직접 참조하지 않고 상품 번호와 사이즈 조합으로 찾아가는 방식 사용 | • 문제상황 : 페이지 이동 시 검색 조건 유실 → 해결방법 : Vue 방식으로 전환하여 데이터만 비동기 교체<br>• 문제상황 : 상품 번호가 시퀀스로 생성되어 상품 등록 후 재고 테이블 연결 불가 → selectKey로 INSERT 전 시퀀스 값을 조회해 상품-재고 양쪽에 사용 및 두 처리를 단일 세션으로 묶어 실패 시 함께 롤백 | • 주문 상세에 재고 번호를 직접 참조하도록 구조 개선<br>• 재고 차감 시 DB 수준의 잠금 처리로 동시성 문제 대응 |
| **유호빈** | • 코드 중복 발생: JSTL `<c:choose>`를 활용한 하드코딩 방식의 별점 구현으로 불필요한 코드 길이 증가 및 유지보수성 저하<br>• 부자연스러운 화면 전환: '좋아요' 버튼 클릭 시 부분 갱신이 아닌 화면 전체가 새로고침이 되는 동기 방식으로 처리되어 화면 깜빡임 발생<br>• URL 매핑 충돌 발생: 요청 주소(main/main.do)가 타 팀원 파트와 중복되어, 서버 혼선으로 메인 상품이 간헐적으로 출력되지 않는 문제 발생 | • 비동기 통신(Ajax) 도입: 카테고리 및 정렬 조건 변경 시 페이지 전체 새로고침 없이 상품 리스트 영역만 즉각적으로 갱신되도록 개선<br>• Vue.js 선제적 도입: 상품 검색 기능에 Vue.js를 직접 적용해 봄으로써 기존 jQuery의 태그 기반의 DOM 제어 방식과 데이터 바인딩을 하는 Vue.js의 차이점을 실무적으로 비교 및 학습<br>• 주소 분리 및 협업 시야 확장: 중복 주소를 고유하게 수정하여 정상화했으며, 내 코드를 넘어 프로젝트 전체 흐름과 타 팀원 작업물 파악의 중요성을 크게 체감함 | • 코드 리팩토링: 별점 등 반복되는 View 영역에 JSTL 반복문 `<c:forEach>`을 적용하여 하드코딩 제거 및 코드 간결화 추진<br>• 비동기 처리 전면 확대 적용: 기존 화면 깜빡임이 발생하던 '좋아요' 및 장바구니 담기 등의 기능들에도 비동기 처리를 확대 적용하여 전체적인 사용자 경험 개선<br>• 사전 소통 및 교차 리뷰 강화: 공통 자원 사용 시 사전에 규칙을 정해 소통하고, 지속적인 코드 리뷰로 통합 과정의 충돌을 원천 차단 |
| **송혜림** | • 쿠키를 활용하여 비회원도 최근 본 상품을 확인할 수 있도록 설계<br>• 화면 적용까지는 완료하지 못하여 로그인 사용자 기능만 구현 | • 업로드한 이미지가 최근 본 상품에서 출력되지 않는 문제 발생<br>• 이미지 경로를 수정하여 정상적으로 출력되도록 개선<br>• 비밀번호 확인 후 회원정보 수정 화면으로 이동하도록 구현<br>• 수정 완료 후 회원정보 조회 화면으로 자연스럽게 연결 | • 개발 전 요구사항을 충분히 분석하여 기능 수정과 재작업을 최소화<br>• 팀원과 기능 흐름을 명확히 공유하여 개발 효율 향상<br>• 구현 전 화면 흐름과 기능을 먼저 설계하는 습관을 기르기 |
